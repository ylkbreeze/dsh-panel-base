# dsh-panel-base · 控制台基座

**版本：** 1.0.0
**许可：** MIT（附加使用规则见 [NOTICE.md](NOTICE.md)）
**适用：** DeepSeek Harness（DSH）≥ 0.2.1-rc.2

一个**只提供壳**的面板基座。

它自己不带任何业务功能——只给你一层框架：身份、工作状态、功能块、更多、设置，以及十四套皮肤。
想要什么功能，往 `modules` 目录丢一个 JSON 就多一块，**不用改一行代码**。

```
┌──────────┬─────────────────────────────────────┐
│  头像     │                                     │
│  姓名     │        功能块（你自己挂的）           │
│  性别     │                                     │
│  生日     │                                     │
├──────────┤                                     │
│ 工作状态  │                                     │
│ 当前状态  │                                     │
│ 当前负载  │                                     │
└──────────┴─────────────────────────────────────┘
│         更多          │        ⚙ 设置          │
└────────────────────────────────────────────────┘
```

## 它是什么 / 不是什么

**是：**
- 一个可以长期挂着当「控制台」的壳
- 一个**零代码**扩展的功能挂载点（JSON 驱动）
- 十四套皮肤，每套有自己的配色、图案、边框和**布局结构**
- 一套事件式的内部约定：模块可以带数据源、带开关、带星图

**不是：**
- 不是一个具体功能（这里没有记忆、没有状态机、没有聊天）
- 不是框架（只是一个插件，装了就有一个面板）
- 不联网、不上报、不收集任何数据

---

## 三层结构

| 层 | 长什么样 | 怎么进 |
|---|---|---|
| **一层 · 主界面** | 身份 / 工作状态 / 功能块 / 更多 / 设置 | 点左侧栏 `▦ 控制台` |
| **二层 · 功能页** | 点一个功能块进来，左边标题（可选心率），右边它的子项 | 点功能块 |
| **三层 · 子项页** | 一行行数值 `62/100`，或者一段文字清单 | 点子项 |

只有声明了心率的模块，二层左边才会出现心电和跳动的爱心。没声明就是一整块内容区，不占位。

## 安装

### 方式一：让 DSH 自己装

把这个目录丢给 DSH，说「装这个插件」。

### 方式二：命令行

```bash
dsh plugin --profile <你的profile名> add /path/to/dsh-panel-base
```

装完重启 DSH，左侧栏会多一个 `▦ 控制台`。

### 方式三：本地链接（开发用）

在 DSH profile 的 `package.json` 的 `dependencies` 里加：

```json
"dsh-panel-base": "link:/绝对路径/dsh-panel-base"
```

## 配置身份

打开 `cordis.patch.yml`：

```yaml
- insert:
    - id: panel-base
      name: dsh-panel-base
      config:
        profile:
          name: '你的名字'
          gender: ''
          birthday: ''
        statusText: '在线'
        loadText: '—'
        statusUrl: ''
```

| 键 | 作用 | 留空会怎样 |
|---|---|---|
| `profile.name` | 姓名 | 显示 `?` |
| `profile.gender` | 性别 | 显示 `—` |
| `profile.birthday` | 生日 | 显示 `—` |
| `statusText` | 工作状态 · 当前状态 | 显示 `—` |
| `loadText` | 工作状态 · 当前负载 | 显示 `—` |
| `statusUrl` | 预留：从接口取状态 | 现在只认固定文字 |

## 加自己的功能

**加一个功能 = 写一个 JSON。**

放这两个地方任选：

| 位置 | 用途 | 升级插件会丢吗 |
|---|---|---|
| 本包 `modules/` | 跟着插件走，随包分发 | 会 |
| `%USERPROFILE%\.dsh\panel-base\modules\` | 你自己的 | **不会** |

> Linux / macOS 是 `~/.dsh/panel-base/modules/`

### 最小示例

```json
{
  "id": "my-feature",
  "标题": "我的功能",
  "说明": "一句话介绍",
  "序号": 10,
  "子模块": [
    {
      "id": "detail",
      "标题": "细节",
      "字段": [
        { "名": "好感度", "值": 0.62 },
        { "名": "精力", "值": 88 }
      ]
    }
  ]
}
```

### 全部字段

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | string | **必填**，唯一。重复的会被忽略 |
| `标题` | string | 功能块上显示的名字 |
| `说明` | string | 副标题 |
| `序号` | number | 小的排前面，默认 100 |
| `心率值` | number | 有就显示心率和爱心，没有就不显示 |
| `星图` | boolean | `true` 时二层改成「左边大图 / 右边竖排」 |
| `数据源` | string | 一个 URL，会每 5 秒拉一次 |
| `插件` | string | 插件包名，配合 `开关` 用 |
| `开关` | boolean | `true` 时功能页顶部出现启用滑块 |
| `子模块` | array | 点进来后的那些格子 |

### 子模块字段

| 字段 | 说明 |
|---|---|
| `id` | 唯一 |
| `标题` | 格子上的名字 |
| `字段` | 数值/文字列表 |
| `按类` | 不写 `字段` 时用：按类型从数据源的 `memories.points` 里筛，显示条数和正文 |

### 字段项

| 字段 | 说明 |
|---|---|
| `名` | 显示的名字 |
| `路径` | 从数据源里取值，如 `state.joy`、`memories.total` |
| `值` | 没有数据源（或取不到）时用的固定值 |
| `型` | `text` 表示文字（长文字会自动排成清单，不是格子） |
| `可复制` | 文字项后面加一个「复制」按钮 |

### 数值怎么显示

- `0–1` 的值 → 显示成 `0–100`（0.62 → `62/100`）
- `0–100` 的值 → 原样显示
- 一个子项里**全是文字** → 自动排成清单，不铺大方格

### 接活数据

写一个 `数据源`，面板每 5 秒拉一次：

```json
{
  "id": "my-data",
  "标题": "我的数据",
  "数据源": "/my-plugin/state",
  "子模块": [
    {
      "id": "nums",
      "标题": "数值",
      "字段": [
        { "名": "心情", "路径": "state.mood" },
        { "名": "精力", "路径": "state.energy" }
      ]
    }
  ]
}
```

`数据源` 写相对路径（`/my-plugin/state`）会自动跟着 DSH 的端口走，重启不用改。

### 加一个能开能关的功能

```json
{
  "id": "yu-room",
  "标题": "鱼屋",
  "插件": "dsh-yu-room",
  "开关": true,
  "子模块": [
    {
      "id": "conn",
      "标题": "连接",
      "字段": [{ "名": "服务器", "型": "text", "值": "wss://example.com/ws" }]
    }
  ]
}
```

写 `插件` + `开关` 之后，功能页顶部会出现一个滑块，点的就是那个插件的启停。

## 皮肤

「⚙ 设置 → 样式」里十四套，**每套不是换个颜色，是换一种界面结构**：

| 皮肤 | 结构 | 图案 |
|---|---|---|
| **默认** | 左栏 + 网格 | 无 |
| **科技屏** | 身份压到顶部横排，功能密格 | 电路板 + 扫描线 + 四角角标 |
| **柔和** | 功能块变成圆图标 + 名字 | 波浪 |
| **玻璃** | 内容居中成浮岛 | 斜方格 + 光晕 |
| **暗夜** | 功能改成左侧竖排菜单 | 细横纹 + 金角标 |
| **纸质** | 两栏书页，衬线字 | 纸纤维点 |
| **霓虹** | 功能块横向一排可滑 | 点阵 + 品红发光 |
| **终端** | 竖排一列，每行 `>` 前缀 | CRT 扫描纹 |
| **新拟物** | 2×2 大格，双向阴影 | 无（靠阴影） |
| **报纸** | 三栏排版，粗黑分隔 | 无 |
| **像素** | 紧密小格，硬边阴影 | 棋盘格 + 四角方块 |
| **气泡** | 功能块带小尾巴 | 双层边 + 四角钉点 |
| **银河** | 左栏稍宽，大格 | **四臂旋涡，140 秒转一圈** |
| **炫彩** | 居中浮岛 | **流动彩虹，18 秒循环** |

### 加一套自己的皮肤

在 `client.js` 的 CSS 里加一段：

```css
.pb-wrap[data-skin="mine"]{
  --pb-bg:#111;
  --pb-card:#1a1a1a;
  --pb-fg:#eee;
  --pb-accent:#0f0;
  /* ……其它变量 */
}
```

然后在设置的下拉列表里加一项就行。变量清单在 CSS 开头的 `.pb-wrap{}` 里。

## 设置项

| 项 | 选项 | 说明 |
|---|---|---|
| 样式 | 十四套皮肤 | 配色 + 图案 + 布局一起换 |
| 大小 | 小 / 中 / 大 | 面板整体缩放（预留，暂未接） |
| 打开方式 | 占一整页 / 浮窗 | 浮窗档预留 |
| 语言 | 中文 / English | 界面文字 |
| 自定义背景 | 图片地址 | 填了头像框就用它 |

设置存在 `%USERPROFILE%\.dsh\panel-base\settings.json`，**卸载插件不丢**。

## 常见问题

**Q：功能块显示不出来？**
检查 JSON 的 `id` 有没有重复，或者 `modules/` 路径对不对。面板 5 秒拉一次数据，等一下或者重开面板。

**Q：皮肤切了没反应？**
旧版本有这个问题（改完没重新拉数据），1.0.0 已修。

**Q：数值全是 `—`？**
`数据源` 取不到，或者 `路径` 写错了。先在浏览器打开那个地址看返回的 JSON 结构。

**Q：功能块被裁掉一块？**
1.0.0 已修（列宽改成 `minmax(min(220px,100%),1fr)`，不会溢出容器）。

**Q：会收集我的数据吗？**
不会。这个插件不联网，所有数据都在你本机的文件里。

**Q：能用在别的 AI 客户端吗？**
不能。它是 DSH 的插件，依赖 DSH 的插件机制和主题变量。
